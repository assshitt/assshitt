#### Selected work

**[Council](https://github.com/assshitt/ai-council)** &nbsp;·&nbsp; 2026<br>
A second opinion for decisions with no single right answer. Three models from different AI labs argue the question from fixed seats, and a chairman from a fourth lab writes one verdict with its confidence and the disagreement left in view. It also runs as an MCP server inside Claude, Cursor and Windsurf. Researched, designed and built solo.<br>
[Live site](https://ai-council-ashen.vercel.app) · [Case study](https://ashitdesign.framer.website/work/projects/council-ai)

**[WYST](https://github.com/assshitt/Wyst-App)** &nbsp;·&nbsp; 2025<br>
A clothing swap platform for college students. You list what you never wear, earn points when someone takes it, and spend them on something you will. Started as a research project on campus and grew into a working MVP in Next.js.<br>
[Live demo](https://wyst-app.vercel.app) · [Case study](https://ashitdesign.framer.website/work/projects/wyst)
